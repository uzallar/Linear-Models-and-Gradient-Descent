# Linear-Models-and-Gradient-Descent
Проект посвящен исследованию линейных моделей и их применению для решения задачи машинного обучения. В рамках работы выполнены анализ данных, подготовка признаков, обучение модели и оценка качества с использованием стандартных метрик.

## Описание проекта

В этом проекте:
- провела первичный анализ данных и подготовку признаков;
- реализовала и сравнила подходы на основе линейных моделей;
- оценила качество модели и проанализировала результат.

## Цель

Построить и оценить модель на основе линейных методов для решения задачи классификации или регрессии на выбранном наборе данных.

## Что сделано

- исследован набор данных;
- обработаны пропуски и категориальные признаки;
- выполнено масштабирование и подготовка данных;
- обучена модель линейной регрессии или линейной классификации;
- проведена оценка качества модели;
- сделаны выводы по результатам эксперимента.
